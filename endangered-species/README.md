# License Plate Frame Project

This repo contains the design, print settings, and notes for a custom 3D printed license plate frame.

## Project Details
- Top Text: THREE RIVERS LOCAL
- Bottom Text: ENDANGERED SPECIES
- Printer: Bambu H2C
- Multi-color: Yes
- Intended Use: Rear Vehicle Plate

## Repo Structure
- design.md → CAD design specs
- print-settings.md → slicer + material settings
